# PR 媒体与记者背调

用于 PR 邀约、采访、试驾、发布会、技术沟通、约稿、新闻稿投放或长期媒体关系判断。只研究媒体机构及其记者、编辑、专栏作者等新闻从业者，不做 KOL 或网红筛选。

用户通常会提供记者姓名/媒体名单、目标品牌，以及背调目的和活动或约稿背景。以这些信息判断本次适配度与合作策略；名单较长时采用一致的证据标准并比较优先级。若缺少目标品牌、市场或活动背景且会改变结论，先补充必要问题；若可先完成职业履历或媒体概况等独立部分，则先完成并明确判断边界。名称有歧义时先核验身份，不要混用不同对象的资料。

## 研究原则

- 记者与媒体分别建档。不要把媒体整体的报道风格直接当作某位记者的个人立场，也不要把一位记者的稿件当成整家媒体的立场。
- 背景限于与工作相关的公开职业信息：任职经历、职位、负责领域、重要报道、公开采访或编辑职责。不要收集无关的私人生活资料。
- 优先查看媒体原文、作者页、编辑团队介绍、媒体官方账号、公司年报、经认证的行业受众测量及原始采访。第三方数据库可作为线索，重要判断需尽量回到原始来源。
- 为每条关键事实保留链接、发布日期或数据时间范围。注明研究截止日期。搜索摘要和转载不能单独支撑关键判断。
- 区分**已确认事实**、**样本分析**、**推断/建议**和**待核实**。样本有限时写明范围，不推断稳定的立场或倾向。
- 对受众数据说明口径、平台、年龄/地区范围、周期、指标类型及数据来源。网站月度受众、访问量、文章阅读量、社媒粉丝数、视频播放量和实际触达不得相互替代。
- 不编造职位、职业经历、文章、标题、日期、引述、受众数据、竞品关系、风险或报道立场。未检索到时写明检索范围和“暂未找到可确认记录”，不要声称“从未报道”。

## 研究与判断

1. **记者职业背景：**核实记者的现任职位、所属媒体、过往公开任职经历、负责领域、重要报道或公开专业表达。按时间整理关键履历；重要报道选择能代表其工作领域、报道方式或编辑职责的样本，并说明选择依据。
2. **任职媒体：**介绍媒体定位、所有者/所属集团（有可靠来源时）、主要市场和语言、核心报道内容、传播渠道及社媒账号。对各平台列出公开账号链接、粉丝/订阅数、查询日期；平台未公开或数据不可见时标“未能核实”。
3. **媒体受众与重要程度：**整理受众构成与规模，包括市场、年龄或兴趣画像（仅限来源提供的数据）。评价媒体在目标市场的影响力，以及与本次品牌、受众和传播目的的相关性。可给“高/中/低/待核实”并解释依据；区分媒体影响力和本次活动适配度，不凭单一流量数字、头衔或未经验证的自称评级。
4. **公司、品牌与竞品报道：**分别检索用户提供的公司本身（包括公司名称、集团/子公司及常见写法）、其相关品牌/产品和主要竞品。公司层面的报道与品牌/产品报道分开整理，不因公司与品牌有关联就混为一类。记录日期、标题与原文链接、作者、报道形式、议题/角度、可核实信息及其对本次沟通的意义。按记者与媒体分开归属；样本较多时选择近期且有代表性的报道，并说明观察区间。
5. **约稿建议：**提出 2–4 个基于记者领域、媒体受众和用户背景的具体选题。每项须写明切入角度、建议形式、可提供的证据/素材、适合的品牌发言人，以及对方可能追问的问题和需准备的回答依据。没有充分依据时，说明还缺少哪些品牌事实、数据、采访对象或活动信息，不为凑数编选题。
6. **本次活动适配与未来关系：**分析记者/媒体与本次活动的受众、主题、形式、时间和新闻价值是否匹配；给出邀约建议、优先级及限制条件。进一步建议适合一次性邀约、持续选题沟通、定期数据/技术交流或重点关系维护，并说明判断依据。不要把编辑关系写成报道承诺。
7. **中国企业外媒背调中的涉华报道分析：**仅在目标为中国企业且对象是外媒时增加此项。分别检查记者和媒体对中国、中国企业及相关议题的既往报道，列出代表性原文、具体措辞/框架和事实依据。可分析是否出现持续、明确且有多篇样本支持的敌意或偏见性叙事，但不要仅凭批评中国政府政策、质疑某家中国企业、负面报道或单篇文章直接定性“反华”。区分对政府政策、企业行为、产品问题和中国群体的描述；样本不足时结论写“无法判断”，并列出需补充的样本。
8. **风险与待核实：**分别列出有来源支持、可能影响沟通或活动执行的风险，以及目前未确认但会改变结论的信息。报道提出质疑、指出产品问题或发表负面意见本身不构成不当风险；需说明其与本次合作的具体关联。

先给出决策摘要：本次适配度与建议、媒体重要程度、邀约优先级、核心证据和主要限制。多人/多家媒体名单先做横向比较，再逐一展开。按下列七部分输出；中国企业背调外媒时，在第 7 部分填写“涉华报道分析”。无可靠依据的字段标为“待核实”。

### 3. 媒体和记者约稿建议

列出 2–4 个选题。每项包含：**选题与切入角度、为何适合该记者/媒体、建议形式、可提供的证据/素材、合适的品牌发言人、可能被追问的问题及需准备的依据**。如信息不足，列出缺口，不虚构选题。

### 4. 本次活动背景适配度与建议

分析主题、受众、活动形式、时机及新闻价值与记者/媒体的匹配度。给出邀约建议、优先级及依据；说明更适合现场采访、试驾评测、提前约稿、背景沟通或后续持续选题。提出适合的未来合作方式和沟通节奏，并明确编辑独立性与报道结果的不确定性。收尾给出 3–5 条可执行行动，包括首选选题/形式、建议对接人、准备材料、需准备的问题及后续关系维护动作；若有多人或多家媒体，写明邀约顺序或分层依据。

### 6. 风险与待核实

分别列出：

- **有来源支持的风险：**说明证据、日期及与本次活动的实际关联。
- **待核实事项：**说明缺少的身份、数据、报道样本、活动信息或其他条件，以及核实后可能如何改变建议。
